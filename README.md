# DÖNER DIOSA FORTUNA

### Menú digital para restaurante

Aplicación web moderna desarrollada para **DÖNER DIOSA FORTUNA**, diseñada para ofrecer a los clientes un acceso rápido al menú del restaurante mediante un código QR.

> Escanea. Descubre el menú. Selecciona tus productos. Enséñaselos al camarero.

---

## Acceso al menú

### [DÖNER DIOSA FORTUNA — MENÚ](https://d-ner-diosa-fortuna.vercel.app/)

La aplicación está diseñada principalmente para dispositivos móviles.

El cliente puede escanear el código QR disponible en el restaurante o acceder directamente al enlace anterior para consultar el menú.

---

## Sobre el proyecto

DÖNER DIOSA FORTUNA es un sistema de menú digital diseñado para facilitar la consulta de la carta desde el teléfono móvil.

El cliente puede:

- Acceder al menú mediante un código QR.
- Navegar por las diferentes categorías.
- Consultar los producto
